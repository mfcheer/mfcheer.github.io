循环数组，即有序的数组进行移位后的数组。  
如：4，5，6，7，8，0，1，2，3

    
    
    查找值是否存在时，利用二分的思想。
    步骤：
    while(L<R)
    如果 a[mid] == key,return mid。
    如果a[mid] >　ａ[L],说明L-mid是有序的，mid+1 - R是循环的
           如果key<a[mid] && key >= a[L]，则key在L - mid-1之间，
           否则key在mid+1 - R之间。
    否则说明mid+1 - R之间是有序的，L-mid是循环的。
           如果key>a[mid] && key <= a[L]，则key在mid+1 - R之间，
           否则key在L-mid - 1之间。

代码：

    
    
    int Find(int a[], int key, int n)
    {
        int l = 0, r = n - 1;
    
        while (l <= r)
        {
            int mid = (l + r) / 2;
            if (a[mid] == key)
                return mid;
            if (a[l] < a[mid])
            {
                if (a[mid] > key && key >= a[l])
                    r = mid - 1;
                else
                    l = mid + 1;
            }
            else
            {
                if (a[mid] < key && key <= a[r])
                    l = mid + 1;
                else
                    r = mid - 1;
            }
        }
    
        return -1;
    }
