遍历数组，遇到第i个元素时，产生一个i到n-1之间的随机数，然后两个位子的数互换。

void shuff(int *ap, int n)

{

    int i;

    for (i=0; i<n; i++)

    {

           int t = rand()%(n-i)+i;

           swap(a[i],a[t]);

    }

}
